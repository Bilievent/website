# SYNC — SCEGA conference permit page

The latest user-supplied conference screenshot is the composition reference. This is a new conference-specific page, not the rejected light proposal and not a color-only rewrite of the older general permit page. It preserves the reference sequence and compact dark composition while applying the supplied SYNC palette through native controls.

## Composition and colors

Desktop content is boxed at 1296px with 24px gutters. Deep Midnight #1D162A is the primary background; Dark Purple #2B203D separates preparation, business names, approach and experience areas and fills cards. Charcoal #3A3447 provides borders and secondary panels. Royal Purple #8F7BB8 fills primary buttons and colors icons; Soft Lavender #C9BCE3 fills the fee and final CTA bands and hover buttons. White #FFFFFF is for headings, Silver Gray #D8D8E0 for supporting dark-surface copy, and Deep Midnight/Graphite #4A4557 for text on the light bands. The supplied Light Gray/Soft White colors remain available for native adjustments; Soft White is also used in the final outline-button hover state. Solid button labels are dark to meet small-text contrast requirements.

Manrope typography: 52px desktop H1, 44px tablet, 35px mobile; mostly 32px section headings, 17–18px card headings and 14–17px body. Cards use 3–9px radii, fine borders and restrained spacing. The decorative circle behind the reference hero photo is omitted to keep the layout within straightforward editable container/image controls.

## Responsive, semantics and compatibility

At 1440px: split hero, four classification columns, three-column preparation, two-column scope/FAQ, four activity cards, and three-plus-two service cards. At 768px: principal rows stack and card collections wrap to two columns. At 390px: single-column cards and form fields, header wordmark/CTA followed by navigation. Native Posts uses responsive 1/1/1 columns for the project and 3/2/1 for guides. The page has one H1, section H2s, descriptive image alt text, semantic section/header/footer/nav tags, labeled fields and no custom motion.

There are 213 elements using Containers, Heading, Text Editor, Image, Icon List, Icon Box, Button, Nested Accordion, Form and Posts. All types are present in the user exports except the native Form and Nested Accordion previously approved by the user. No HTML Widget, custom CSS/JS, shortcode or add-on code is delivered. The renderer and browser controllers are independent QA infrastructure, not page implementation.

Schema 0.4 is the saved-template file format, not an Elementor version. Pro Posts/Form and native Containers/Nested Elements are required. Public official core and GPL compatibility sources corroborate added control names but do not certify the installed Elementor Pro version. Exact installed versions and a WordPress staging runtime remain unavailable. This is a validated saved-template prototype pending native import, editor reopening and re-export; it is not an official tested Website Kit.
