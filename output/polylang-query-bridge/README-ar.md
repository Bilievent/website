# ربط استعلام المشاريع بلغة محددة — Polylang + Elementor Pro

هذا ربط خادم محدود باستعلامين مسمّيين فقط؛ تم تجهيزه بعد بلاغ ظهور النسختين العربية والإنجليزية عند اختيار قسم. يضيف lang صريحًا لاستعلام WordPress بدل الاعتماد على لغة الكوكي/آخر زيارة. لا يغيّر لغات المحتوى أو روابطه أو إعدادات LiteSpeed تلقائيًا.

## التثبيت والإعداد على staging

1. احتفظي بنسخة احتياطية، ثم من **Plugins → Add New → Upload Plugin** ارفعي `syncs-projects-language-bridge.zip` وفعّليه. هذا ملف إضافة WordPress؛ لا يُستورد من مكتبة قوالب Elementor.
2. من **Tools → SYNCs Projects Languages**، تأكدي أن `project` و`project_category` يظهران Enabled. اختاري رمز اللغة العربية الفعلي للاستعلام العربي، والإنجليزية للاستعلام الإنجليزي، واحفظي. القائمة مأخوذة من لغات Polylang المسجلة؛ الرمزان الافتراضيان ar/en ليسا فرضًا على إعداداتك.
3. افتحي صفحة المشاريع **الإنجليزية** أو قالب الأرشيف الإنجليزي في Elementor. حددي Loop Grid → Query → **Query ID** واكتبي: `syncs_projects_en`.
4. افتحي نسخة الصفحة/قالب الأرشيف **العربية** المرتبطة عبر Polylang، وفي نفس الحقل اكتبي: `syncs_projects_ar`.
5. اتركي Taxonomy Filter مرتبطًا بالـLoop Grid الصحيح وبتصنيف `project_category`. لا تستبدلي استعلاماته أو أسماء أقسامه بكود ثابت. لا تغيّري Posts per page أو ترتيب المشاريع لمجرد تركيب الربط.
6. احفظي الصفحتين وامسحي كاش روابطهما المتأثرة من LiteSpeed، ثم اختبريهما كزائرة غير مسجلة، بما فيه اختيار الأقسام بعد زيارة اللغة الأخرى. لا يلزم تعطيل LiteSpeed كله.

لا تضعي Query ID واحدًا ثابتًا في قالب مشترك يعرض اللغتين؛ كل ID مربوط بلغة صريحة. إذا كان /project/ أرشيفًا يستخدم قالبًا واحدًا مشتركًا، يلزم أولًا تحديد/ربط نسخة Elementor الصحيحة لكل لغة في إعدادات الترجمة/Theme Builder الموجودة عندك. هذه الإضافة لا تنشئ تلك النسخ أو تغيّر شروط العرض.

## إعداد المحتوى والتصنيفات

- من Languages → Settings → Custom post types and Taxonomies تحققي من تفعيل ترجمة `project` و`project_category`.
- راجعي لغة كل مشروع وقسم وربط ترجمته؛ الاسم العربي وحده لا يعيّن لغة السجل. الأقسام التي لا تحتوي مشاريع منشورة في لغة الصفحة قد تختفي وفق إعداد الفلتر الحالي show_empty_items.
- لو حالة الأنواع/التصنيفات أو اللغة غير جاهزة، الاستعلامان المرتبطان بالإضافة يرجعان بدون نتائج بدل عرض كل اللغات. راجعي شاشة Tools المذكورة؛ الإضافة لا تُسنِد لغات جماعيًا أو تحوّل بياناتك.
- أسماء الأقسام نفسها تأتي من Polylang/Taxonomy Filter. لو قائمة الأقسام تجمع اللغتين قبل النقر، يحتاج تعيين لغة مصطلحات التصنيف وسياق عرض الفلتر مراجعة مستقلة. هذه الإضافة تقيد **المشاريع المرجعة** ولا تعيد كتابة أسماء الأقسام أو تخفي سجلات الخادم في المتصفح.
- حقول روابط ACF تبقى كما في المحتوى؛ الربط لا يترجم قيمة project_url أو يصلح تلقائيًا رابطًا خاطئًا مخزنًا في المشروع.

## إصلاح الواجهة الاختياري

`SYNCs-Filter-UI-Patch.zip` يحتوي الإصلاح المرفق لحالة الكروت والعداد وأوصاف التنقل وRTL، مع تعليمات استبدال HTML widget فقط. لا تعيدي استيراد الصفحة الإنجليزية الكاملة فوق صفحة عربية مترجمة. إصلاح الواجهة وحده لا يقيّد لغة استعلام WordPress.

## دليل الاختبار قبل النشر

- في العربية، اختاري All/الكل ثم قسمًا واحدًا، وتحققي أن عناوين المشاريع/روابطها عربية فقط. كرري في الإنجليزية.
- زوري الإنجليزية ثم ارجعي لتبويب العربية واضغطي الفلتر، والعكس. القيدان الصريحان لا يستخدمان لغة الكوكي في اختيار lang.
- اختبري قسمًا لا يحتوي مشاريع، ومشروعًا بلغته الصحيحة، وترقيم/Load More الأصلي.
- إذا لم يعمل قيد Query ID أثناء طلب تحديث الفلتر في إصدار Elementor Pro المثبت، لا تعتمدي هذه الإضافة كحل مثبت. يلزم تسجيل الطلب/إعدادات نسخة Pro وفحص مسارها الفعلي؛ لا توجد اختبارات تشغيل Pro على الموقع من هذه البيئة.

## حدود الأدلة والاختبارات

اختُبرت صياغة PHP ومحاكاة عقد Hook Elementor/API Polylang على PHP 7.4 و8.3 و8.5: العربية والإنجليزية، كوكي/طلب بلغة مخالفة، الحفاظ على tax_query والترقيم والكاش، رموز لغات مخصصة، وإرجاع آمن بلا نتائج عند غياب Polylang أو الإعدادات. انظري validation/results.json. لا توجد ادعاءات بأن تلك المحاكاة شغّلت WordPress/Elementor Pro الحقيقيين.

الصفحة الحية https://syncs.com.sa/project/ محجوبة من بيئة العمل بقرار وسيط الشبكة 403. أكدتِ أن المشكلة مستمرة عبر `?LSCWP_CTRL=before_optm`؛ هذه المقارنة لا تستبعد كل طبقات الكاش، لكنها لا تدعم الاكتفاء بتعطيل تحسينات الصفحة كحل. لم يتم تثبيت الإضافة أو تغيير Polylang أو LiteSpeed على موقعك بواسطة هذه المحادثة.

يعتمد الربط على Hook Elementor الموثق `elementor/query/{query_id}` وعلى دوال Polylang العامة `pll_languages_list`, `pll_is_translated_post_type`, `pll_is_translated_taxonomy` ومعامل WP_Query lang. لا توجد فلاتر pre_get_posts عامة أو SQL مخصص أو إيقاف للكاش أو اعتراض لطلبات fetch.

## الرجوع عن التعديل

امسحي Query ID من النسختين ثم عطّلي الإضافة، وامسحي كاش روابط الصفحتين. تعطيل الإضافة لا يحذف مشاريع أو تصنيفات أو لغات. خيار ربط اللغات يظل محفوظًا لإعادة التفعيل؛ لا يوجد حذف تلقائي للبيانات.
