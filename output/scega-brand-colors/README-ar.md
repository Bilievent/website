# ملف صفحة SCEGA كاملًا — تعديل الألوان فقط

استخدمي **SYNCs-SCEGA-Complete-Page-Brand-Colors.json**. هو نفس تصميم الملف الكامل السابق، بعد تعديل توزيع ألوانه حسب باليت SYNC. لا توجد سكاشن جديدة أو تغيير في المحتوى أو الصور أو الـWidgets.

الهيرو والهيدر والفوتر والأسئلة والتواصل بألوان Midnight وDark Purple؛ أقسام المحتوى بخلفيات Light Gray وSoft White؛ الأزرار والأيقونات بلمسات Royal Purple وSoft Lavender؛ النصوص فاتحة أو داكنة بحسب الخلفية. النص على الأزرار الموف داكن للحفاظ على وضوحه.

## الاستيراد

1. حمّلي ملف JSON مباشرة، أو فكي ضغط ZIP أولًا.
2. من WordPress → Templates → Saved Templates → Import Templates اختاري ملف JSON.
3. أدرجي القالب داخل صفحة تجريبية بـElementor. استخدمي Elementor Canvas إذا أردتِ عرض الهيدر والفوتر الموجودين داخل القالب.
4. راجعي الكمبيوتر والتابلت والموبايل، وافتحي المحرر مجددًا بعد الحفظ قبل تطبيقه على الصفحة المنشورة.

يحتاج نفس متطلبات الملف الأصلي: Elementor وElementor Pro المتوافقين مع Containers وNested Tabs وNested Accordion وForm. نموذج التواصل يحتفظ بإجراء Collect Submissions نفسه؛ اختبري الحفظ داخل موقعك. روابط الصور والخدمات والتواصل لم تتغير. لا يوجد HTML Widget أو CSS/JS مخصص.

نجح فحص JSON، وثبات جميع القيم غير اللونية، وتباين الألوان، والمراجعة التقريبية للتخطيط عند 1440 و768 و390 بكسل. لم يُختبر الاستيراد وإعادة التحرير داخل WordPress لعدم توفر نسخة تجريبية أو أرقام إصدارات Elementor/Pro. رقم 0.4 هو صيغة JSON، وليس إصدار الإضافة. ZIP يجمع الملف والتعليمات، وليس Website Kit رسميًا.
