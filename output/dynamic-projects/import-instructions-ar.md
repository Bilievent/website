# تركيب قسم المشاريع الديناميكي في Elementor Pro

هذه الحزمة مبنية على ملف Loop Item #6526 الذي أرسلته. الصور والعناوين تأتي من المشاريع التي يرجعها استعلام Elementor، ولا توجد قائمة مشاريع ثابتة في القالب. الربط الفعلي للـLoop Grid والـTaxonomy Filter يُضبط مرة واحدة في محرر Elementor، لأن ملفك المرفق لم يحتوِ عليهما.

## قبل البدء

- استخدمي staging واعملي نسخة احتياطية من الصفحة وقالب Loop Item #6526. استوردي القالب الجديد باسم مستقل بدل استبدال القديم مباشرة.
- احتفظي بإصدارات WordPress وElementor وElementor Pro واسم الثيم في سجل الاختبار. الإصدارات غير مذكورة في ملف التصدير.
- حقل ACF `project_url` يجب أن يكون متاحًا ويحتوي رابطًا صحيحًا لكل مشروع. تم الحفاظ على معرّف الحقل الأصلي `field_69d0254b84115`؛ الحزمة مخصصة لنفس الموقع/مخطط الحقول. إذا أردتِ رابط صفحة المشروع العادي بدل هذا الحقل، اختاري Post URL من Dynamic Tags لرابط الصورة ورابط العنوان داخل Elementor.

## خطوات التركيب

1. فكّي ضغط الحزمة. من Templates / Saved Templates استوردي `templates/syncs-dynamic-loop-item.json`. نوعه الأصلي `loop-item`، واسمه يبدأ بـ **SYNCs — Dynamic project card**. بعد الاستيراد تأكدي أنه متاح ضمن قوالب Loop Item. لا تعتمدي على رقم 6526: القالب المستورد قد يأخذ رقمًا جديدًا.
2. استوردي `templates/syncs-projects-section-shell.json` وأدرجيه في صفحة staging. هو Container بداية يحتوي العناوين وتنسيق القسم والتحكم، وليس Query أو Filter مُجهّزًا. لا تستورديه كـWebsite Kit.
3. داخل نفس الـContainer الخارجي، أضيفي **Loop Grid** أصلي من Elementor Pro بين العناوين وHTML widget. اختاري له قالب **SYNCs — Dynamic project card** المستورد.
4. في Query اختاري نوع المحتوى الذي يحتوي مشاريعك فعلًا. استخدمي استعلامًا ديناميكيًا، ورتّبي بتاريخ النشر من الأحدث للأقدم إذا أردتِ ظهور الجديد أولًا. لا تختاري قائمة مشاريع يدوية إذا كان هدفك إضافة المشاريع الجديدة تلقائيًا. ابدئي بـ4 عناصر لكل صفحة. يمكن زيادة العدد أو استخدام الترقيم الأصلي لاحقًا بعد اختباره.
5. في Loop Grid > Advanced > CSS Classes اكتبي `sx-live-grid` بدون نقطة. الـContainer الخارجي المستورد يحمل بالفعل `sx-live-projects`. لو استخدمتِ سكشن من عندك بدل ملف shell، أضيفي له هذا الكلاس وضعي كود `assets/loop-grid-integration.html` كاملًا في HTML widget واحد داخل نفس السكشن بعد الـLoop Grid.
6. أضيفي **Taxonomy Filter** الأصلي فوق الـLoop Grid، واربطيه بالـLoop Grid الصحيح من إعدادات الويدجت. اختاري الـtaxonomy الذي يمثل أقسام مشاريعك بالفعل. لم يتم افتراض اسمه لأن ملف Loop Item لا يذكره. لو التصنيف لا يظهر، تأكدي أنه مسجل لنفس نوع المحتوى المستخدم في Query، وأن المشاريع مرتبطة بمصطلحاته.
7. اضبطي ألوان وخطوط أزرار الفلتر من Style في Elementor. التنسيق المرفق لا يغيّر استعلام الفلتر أو سلوكه أو أسماء أقسامه. الـHTML widget يغيّر طريقة عرض نتائج Loop Grid فقط.
8. افتحي قالب Loop Item واختاري مشروعًا حقيقيًا في Preview Settings إن كانت المعاينة بلا بيانات. الصورة تستخدم Featured Image، والعنوان Post Title، والرابط ACF project_url كما في التصدير الأصلي. لا حاجة لاختيار صورة مختلفة يدويًا لكل بطاقة في الصفحة.
9. احفظي، وافتحي الواجهة الأمامية خارج المحرر، واختبري كل قسم من الفلتر. امسحي cache وأعيدي توليد Elementor CSS/data إذا بقي التصميم القديم.

الترتيب داخل السكشن: العناوين ← Taxonomy Filter ← Loop Grid ← HTML للتنسيق/التحكم.

## اسم القسم داخل البطاقة — اختياري

ملفك لم يتضمن Post Terms أو اسم taxonomy. لإضافة الشارة مثل المرجع: أضيفي Heading native داخل Loop Item بين الصورة والعنوان، اختاري Dynamic Tags > Post Terms إن كان متاحًا، وحددي تصنيف المشاريع الصحيح. اختاري Paragraph كوسم HTML، وضعي الكلاس `sx-live-term` في Advanced > CSS Classes. تنسيق الشارة جاهز في CSS، لكن الربط لا يمكن تخمينه من الملف الحالي.

## طريقة العمل

- مصدر البيانات هو Query الأصلي في Elementor. المشاريع الجديدة تظهر عندما تستوفي Query وحالة النشر والتصنيف، مع مراعاة cache والترقيم.
- الفلتر يظل Taxonomy Filter الأصلي، ويحدد النتائج. الكود يلاحظ تبدّل DOM الخاص بنتائجه، دون إنشاء استعلام منفصل أو اعتراض طلباته.
- الأسهم تتنقل بين النتائج المحمّلة حاليًا فقط؛ لا تجلب الصفحة التالية تلقائيًا. الترقيم/Load More يظل مسؤولية Loop Grid الأصلي.
- على سطح المكتب تظهر حتى أربع بطاقات في نافذة العرض، وتكبر البطاقة المختارة. إذا كانت النتائج أكثر يمكن تمرير الشريط أفقيًا. في الهاتف يوجد تمرير أفقي والتقاط للبطاقات.
- الـLoop Item يحتوي Image وIcon Box native للعنوان الديناميكي وHTML صغيرًا للتنسيق فقط. عنصر Icon الإضافي الذي احتاج مكتبة Themify أُزيل؛ لم يتغير رابط الصورة أو العنوان.
- التنسيق والحركة مخصصان بـCSS/JS. الصورة والعنوان وروابطهما قابلة للتعديل في Elementor، لكن تفاصيل الحركة تُعدّل في HTML widget.

## اختبار مطلوب قبل النشر

اختبري 1440 و768 و390 بكسل، وكل تصنيفاتك، وقسمًا بلا نتائج، ومشروعًا جديدًا، وصورًا بأبعاد مختلفة، وصحة روابط ACF، والتنقل بلوحة المفاتيح. افتحي القالب مجددًا وتأكدي أن عناصره قابلة للتعديل، ثم صدّريه وأعيدي استيراده في نفس staging.

لا توجد نتيجة اختبار WordPress/Elementor فعلية هنا؛ اختبارات المتصفح كانت على محاكاة محلية لبنية Loop Grid وتبدّل نتائج الفلترة. لو سياسة CSP أو إضافة حماية تمنع inline scripts، يلزم نقل CSS/JS إلى آلية تحميل معتمدة على الموقع بواسطة المطور. لا تعطلّي الحماية عالميًا.

لو احتجتِ ملفًا واحدًا يشمل الربط النهائي: بعد اختيار Query والـtaxonomy داخل Elementor، صدّري السكشن كاملًا الذي يحتوي Loop Grid + Taxonomy Filter، مع أرقام إصدارات Elementor/Pro. وقتها يمكن فحص إعدادات الربط الفعلية بدل افتراضها.
