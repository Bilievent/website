# SYNC — SCEGA permit support page

## Scope and reference

Recreate the complete supplied long page as native Elementor saved templates, with the user's palette and images already present in SYNC's same-site exports. The screenshot has fourteen parts: header, split hero, client-style strip, five permit tabs, five preparation cards, service-scope panel, five event-service cards, hotel/visa panel, fee explanations, project showcase, FAQ grid, event-brief form, four resource cards and footer.

The user authorized native Form and Accordion widgets in addition to types already in the earlier exports. The result contains no HTML widgets, custom frontend CSS/JS, shortcodes, plugin payloads or external image files. All content and layout are native editable controls. It is a saved-template prototype pending WordPress staging import, not an official tested Website Kit export.

## Composition

1296px boxed content at desktop with 24px page gutters, a 48/48 split hero, 54px H1, 28px section headings and 13–15px body copy in Manrope. Cards use Dark Purple panels, Charcoal borders and 6–10px radii. Lavender primary buttons use Deep Midnight text. Secondary buttons are transparent with purple borders and lavender text. Most section padding is 22px vertically to preserve the reference's compact, continuous page rhythm.

Native structure totals 236 elements: 124 Containers, 39 Headings, 29 Text Editors, 20 Buttons, 10 Icon Boxes, 9 Icon Lists, one Nested Tabs widget, three Nested Accordions and one Form. Exactly one H1; section headings are H2 and card titles H3. No arbitrary CSS selectors tie content to the renderer.

## Responsive behavior

Desktop: two-column hero/scope/forms, a left permit index and right permit panel, five-column preparation/services, three-column stay imagery and four-column resources. At the native tablet breakpoint rows stack; card collections wrap into two columns. The header wordmark/contact stay on the first line and navigation moves below. Mobile cards and form fields become one column, hero type reduces to 36px, and permit navigation uses the native widget's mobile behavior. Individual layouts follow the site's actual Elementor breakpoint settings.

An independent native-setting review at 1440/768/390px verifies intended widths and content order, all five tab contents, all nine accordion items, basic keyboard interaction, native fragment destinations and browser form constraints. It is not an Elementor/WordPress render. The review's temporary HTML/CSS and tab controller are test infrastructure only and never enter the saved templates or ZIP.
