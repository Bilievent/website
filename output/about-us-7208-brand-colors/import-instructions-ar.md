# استيراد النسخة المعدّلة

الملف الكامل: **SYNCs-About-Us-7208-Brand-Colors.json**. يحتوي على كل محتوى ملفك المرفق بعد تعديل الألوان. الـZIP حزمة تحميل تضم نفس ملف JSON والتعليمات؛ ليس Website Kit رسميًا.

1. احتفظي بتصدير الصفحة الحالية كنسخة احتياطية.
2. فكّي ضغط ملف ZIP.
3. من ووردبريس افتحي Templates → Saved Templates → Import Templates، واختاري ملف JSON.
4. افتحي صفحة مسودة بـElementor، ثم أيقونة المجلد → My Templates، وأدرجي القالب المستورد.
5. راجعي العرض على الكمبيوتر والتابلت والموبايل والأزرار عند المرور عليها قبل النشر.

كل العناصر تظل Widgets أصلية قابلة للتعديل. توجد Widgets من Elementor Free وAnimated Headline من Elementor Pro كما في ملفك. مكتبات الأيقونات والخطوط المستخدمة في الأصل تظل كما هي، وتحتاج أن تكون متاحة في موقعك. الألوان أصبحت محلية داخل القالب، ولا تغيّر Site Settings لبقية موقعك.

تم فحص بنية JSON ومقارنة النسخة بالأصل وفحص تباين الألوان. الاستيراد الفعلي داخل ووردبريس لم يُجرَّب في بيئة العمل، وإصدارات Elementor وPro الدقيقة غير متاحة.
