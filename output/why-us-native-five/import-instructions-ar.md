# قسم Why Us بخمس خدمات — بعناصر Elementor الأصلية

هذه النسخة تستخدم أنواع الـWidgets الموجودة فعلًا في قالبك: Heading وText Editor وIcon List وButton، مع Containers للترتيب والصور. لا يوجد HTML Widget أو CSS أو JavaScript مخصص في القسم.

## أي ملف أستورد؟

- **SYNCs-All-Sections-Native-Why-Us.json**: القالب كاملًا، بأول ثلاثة سكاشن كما هي بعد تعديل الألوان، وقسم Why Us الجديد بدل القديم. هذا هو الملف الذي فيه كل السكاشن.
- **SYNCs-Why-Us-Native-5-Services.json**: قسم Why Us الجديد وحده لو هتضيفيه لصفحة سبق تعديلها.

فكي ضغط ملف التحميل، ثم من WordPress → Templates → Saved Templates → Import Templates استوردي ملف JSON المناسب. افتحي صفحة تجريبية بـElementor وأدرجي القالب من My Templates. اختاري طريقة واحدة، ولا تضيفي القالب الكامل والقسم المنفصل في نفس الصفحة.

## تعديل القسم من المحرر

1. العنوان: عنصرا Heading بعنواني Five ways in. وOne way of working.
2. القائمة اليسرى: Icon List بخمس روابط داخلية. كل رابط ينقل لبطاقة الخدمة المقابلة؛ لا توجد فلترة ولا تبويبات تخفي المحتوى.
3. عناوين الخدمات والأكواد: Heading. الأوصاف: Text Editor. الكلمات التعريفية والنقاط: Icon List.
4. الصور: اختاري Container المسمى باسم الخدمة ثم photo، وادخلي Style → Background. الصور روابط موجودة من موقعك؛ لا توجد صور جديدة أو ملفات صور داخل الحزمة. صورة المعرض مستخدمة للخدمتين Production وTechnology كصورة توضيحية قابلة للتغيير.
5. الأزرار: Button، بعنوان Discuss this service، ومربوطة حاليًا برابط التواصل المعتمد https://syncs.com.sa/contact-us/. لم تُرسل روابط صفحات الخدمات؛ لما تتوفر، غيري رابط كل زر واسم الزر إلى Explore this service إذا رغبتِ.
6. القائمة مثبتة على الكمبيوتر فقط باستخدام Sticky الأصلي في Elementor Pro. راجعي Offset 120 حسب ارتفاع الهيدر عندك. على التابلت والموبايل القائمة فوق البطاقات. كل التنسيق والمسافات والألوان أحجام أصلية قابلة للتعديل، بدون لصق أكواد.

اختيرت الخمس خدمات التي وافقتِ عليها: Event Management وEvent Production وEvent Technology وAVL Solutions وBrand Activation. نص Event Management مبني على الصورة، وبقية الأوصاف والنقاط صياغة مقترحة قابلة للتحرير. روجعت الألوان حسب الباليت السابقة.

فحص JSON والروابط الداخلية والعرض التقريبي اكتمل محليًا. لم يتوفر WordPress تجريبي أو أرقام الإصدارات الدقيقة، وتعذر فتح موقعك من بيئة العمل بسبب رفض الاتصال من وسيط الشبكة. الاستيراد وإعادة فتح المحرر والتصدير، تحميل الصور، الخط Manrope، تثبيت القائمة، وسلوك هيدر موقعك تحتاج تجربة فعلية قبل النشر. هذه ملفات Saved Templates، وليست Website Kit رسمية.
