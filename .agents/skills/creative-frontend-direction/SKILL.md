# Creative Frontend Direction
Inspect visual references for typography, contrast, whitespace, editorial grids, imagery, colors and motion. Produce a design-spec with source-vs-inference distinctions and 1440/768/390 breakpoints. Offer an original branded adaptation where reference is third-party. Avoid generic repeated cards and inaccessible movement. Apply to native Elementor widgets/containers; test visuals before claiming fidelity. Inspiration: https://github.com/Enixes/astra-frontend-design. This is a lightweight local workflow, not an installation of that external repo.
