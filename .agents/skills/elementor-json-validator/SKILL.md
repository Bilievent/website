# Elementor JSON Validator
Read a known-good template export from user's precise Elementor installation. Validate JSON syntax, element tree, element IDs, widget names, settings and assets. Distinguish Elementor Free/Pro/add-on widgets and reject invented controls. Import into staging, render, reopen editor, then verify editability. Official website kit ZIP != simple ZIP of saved-template JSON. If testing cannot be performed, explicitly label result prototype. Inspiration: https://github.com/Moksa1123/elementor-headless; the actual npm tool is NOT installed through this file.
