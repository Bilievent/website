# Codex project instructions — Elementor Creative Kits

For requests involving WordPress Elementor, templates, website references, screenshots, Webflow/Figma recreation, or scroll-driven sections, use the repository skill `.agents/skills/elementor-ref-kit/SKILL.md`.

The output must prioritize native Elementor Containers and widgets, verified editable JSON, responsive design, a separate reference/design specification, accessibility, semantic SEO markup, and documented compatibility with the installed Elementor (Free/Pro) version.

Treat website design references as inspiration unless owned by the user. Never invent controls or call a ZIP an official Elementor Website Kit without import/re-export testing. Work in staging or LocalWP first, do not publish to production without approval.
